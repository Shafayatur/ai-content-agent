# Platform Style Guide

## LinkedIn
- Character range: 800-1300 characters performs best.
- Format: short paragraphs (1-3 sentences), line breaks between them, max 3 hashtags at the end.
- Best posting window: Tue-Thu, 8-10am ET.

## X / Twitter
- Character limit: 280 per post; use a numbered thread (2-4 posts) for longer content.
- Format: punchy, one idea per post, max 1 hashtag per post.
- Best posting window: weekdays, 9-11am ET or 6-8pm ET.
